# Amazon IoT Device Defender (amazon-iot-device-defender)
AWS IoT Device Defender is a security service that lets you continuously audit security policies applied to your IoT devices to make sure they are not deviating from security best practices. It allows you to detect abnormal device behavior and receive alerts for investigation and remediation.

### AWS IoT Device Defender API
